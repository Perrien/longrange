# Reticle Pattern Library + Authoring Workflow

Status: open
Filed: 2026-08-13

A second and third reticle pattern beyond today's MIL/MOA hash — a Christmas-tree windage-hold grid
and/or a BDC holdover grid — plus a repeatable way to author further patterns including owner-designed
ones. The recommended approach is a list of line and point coordinates in mil offsets from centre, the
same shape the existing cadence table takes, so new patterns inherit the exact FFP scaling math for
free; raster art is not recommended at 35×. Detail in `Design/feature-catalog.md` §C.
