# Retrofit The Shared Environment Onto Every Range

Status: open
Filed: 2026-08-13

The config-driven environment module (sky, fog, lights, textured ground, instanced mountains and trees)
shipped with the Test Range and was upgraded again by the Wooded Zero Range, so the system exists —
what is missing is the retrofit. Range A and the sight-in bay are still undressed strips, and every new
range should be built on the module rather than beside it.
