# Transonic Dispersion — Groups Opening Through Mach 1

Status: open
Filed: 2026-08-13

Groups should open unpredictably as a bullet decelerates through Mach 1, but the engine's only scatter
sources — MV SD, BC SD and rifle precision — know nothing about Mach number, so a round arriving at Mach
0.9 gets exactly the same angular scatter as one arriving at Mach 2.5. The consequence is that going
transonic currently costs the player nothing, which would make high-velocity .22 LR a straight upgrade
when in reality competitors buy subsonic match ammo precisely because HV groups worse. Owner
deliberately parked it 2026-07-29 with the DOPE book's amber/red row markers as the honest interim;
research first, and it blocks the HV .22 LR and .22 WMR catalog additions.
